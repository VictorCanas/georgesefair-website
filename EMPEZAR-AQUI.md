# 🚀 Empezar aquí — Modificar la web en 3 pasos

Esta web se edita hablándole a una IA (Claude o ChatGPT) en español normal.
No necesitas saber programar. Sigue estos 3 pasos.

---

## 1️⃣ Instala la herramienta (una sola vez)

**Opción A — Claude Code (recomendada, la más fácil):**
1. Descarga la app de Claude: **https://claude.ai/download**
2. Ábrela y entra con tu cuenta.
3. En Claude, elige **abrir una carpeta / proyecto** y pega esta dirección para descargar el sitio:
   `https://github.com/VictorCanas/georgesefair-website`

**Opción B — ChatGPT:**
- Funciona, pero es más manual (tienes que copiar y pegar archivos a mano).
- Para la mejor experiencia usa **ChatGPT con Codex / acceso a tu computadora**, no el chat normal.

---

## 2️⃣ Pega este mensaje para que la IA se prepare sola

Copia y pega **tal cual** este mensaje en Claude (o ChatGPT) como primer mensaje:

```
Eres el encargado de mantener el sitio web georgesefair.com.
Primero lee los archivos HANDOFF.md y README.md de este proyecto para
entender cómo funciona. Luego prende la vista previa con "npm run dev"
y quédate listo. Yo te voy a pedir cambios en español, uno por uno.
Antes de publicar, siempre revisa que no haya errores y muéstrame cómo
quedó. Cuando te diga "publica", sube los cambios a producción.
```

La IA leerá las instrucciones, arrancará la vista previa y quedará lista.

---

## 3️⃣ Pide tus cambios (ejemplos que puedes copiar)

Escríbele en español lo que quieres. Algunos ejemplos:

- `Cambia el precio del curso Reset Mental a $97 USD.`
- `Cambia el subtítulo principal a: "Fe aplicada. Resultados reales."`
- `Reemplaza los videos de Kingdom Builders por estos: [pega los enlaces de Google Drive]`
- `Agrega un testimonio de "Juan Pérez": "Mi vida cambió por completo..."`
- `Cambia la foto número 3 del collage del Dr. George.`
- `Revisa que todo se vea bien.` ← (corre la revisión automática `/ui-check`)

Cuando estés conforme, di:

- `Publica los cambios.`

En ~1 minuto estará en georgesefair.com. ✅

---

### 📌 3 reglas para no equivocarte

1. **Un cambio a la vez.** Pide uno, revísalo, y sigue con el próximo.
2. **Revisa antes de publicar.** Di *"muéstrame cómo quedó"* antes de *"publica"*.
3. **Si algo sale mal**, di *"revierte el último cambio"*. Siempre se puede volver atrás.
